# ДК Б6К — интерактивная диаграмма Ганта

Интерактивная дорожная карта по сборке, созданию, расчёту и актуализации моделей пласта (Б6К).

## Запуск

Для вкладки статистики нужен локальный сервер (`fetch` JSON):

```bash
npx --yes serve .
```

Вкладка «Дорожная карта» открывается и напрямую через `index.html`.

## Вкладки

1. **Дорожная карта** — Гант, drill-down, масштаб времени, текущие задачи
2. **Статистика моделей** — donut по месторождениям ДО (размер = валовая годовая добыча, сегменты = ДО / СПекТР / УБД)
3. **Системный подход** — единые требования к данным и расчётам для всех ДО

## Данные

```text
data/models-stats.xlsx   # исходная сводная таблица моделей
data/models-stats.json   # нормализованные данные для диаграмм
```

## Возможности Ганта

- Стримы: подготовка данных, создание/расчёт моделей, актуализация, **доработка ИС Б6К**
- Периметр ДО с волнами Top 1 / Top 2 / Top 3
- Drill-down, линия «сегодня», выполненные плашки
- Масштаб: кварталы / месяцы
- Фактические задачи ННГ / СН-МНГ, ППД (ДО, СПекТР, УБД)
