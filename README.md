# ДК Б6К — интерактивная диаграмма Ганта

Интерактивная дорожная карта по сборке, созданию, расчёту и актуализации моделей пласта (Б6К).

## Запуск

Откройте `index.html` в браузере:

```text
file:///C:/Users/AlexanderSyundyukov/Desktop/dk-b6k-gantt/index.html
```

Или поднимите локальный сервер:

```bash
npx --yes serve .
```

## Возможности

- 3 стрима: подготовка данных, создание/расчёт моделей, актуализация
- Периметр ДО с волнами Top 1 / Top 2 / Top 3
- Drill-down во внутренний Гант по клику на плашку
- Линия текущей даты, статус «выполнено» (зелёная заливка + контур легенды)
- Масштаб времени: кварталы / месяцы, ползунки ширины и сдвига
- Адаптивные подписи на плашках + полный текст по наведению
- Блок «Текущие задачи» в боковой панели
- Фактические задачи по ННГ и СН-МНГ
